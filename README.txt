ПРОСТИЙ ВАРІАНТ: ТВІЙ НОУТБУК + STREAMLIT

Основні файли:
  test.ipynb — твій ноутбук з тією самою моделлю та навчанням.
  app.py     — весь інтерфейс в одному файлі.

1. Поклади свої train.csv і test.csv у папку data поруч із ноутбуком.
2. Відкрий test.ipynb та виконай комірки по черзі.
   Якщо модель вже навчена у твоєму відкритому ноутбуці — скопіюй і виконай
   лише останню комірку. Вона збереже model.h5 та model_info.json.
   Ці два файли повинні лежати поруч із app.py.
3. У терміналі в цій папці виконай:
   python -m pip install -r requirements.txt
   python -m streamlit run app.py
4. Завантаж test.csv або його частину з тими самими колонками.
   Натисни «Розпізнати», переглянь і завантаж результати.

Уже встановлені бібліотеки не потрібно встановлювати заново; якщо бракує
тільки Streamlit: python -m pip install streamlit.

Що змінилось у ноутбуці:
- виправлено текстові назви класів у classification_report;
- додано останню комірку збереження моделі та порядку колонок для app.py;
- уточнено коментар, що 561 ознака — це не часові відліки;
- очищено старі збережені результати й повідомлення про переривання.
Архітектура, epochs=15, batch_size=64, датасет і виклик fit залишені твоїми.
Навчених ваг від твоєї моделі в наданому файлі не було, тому їх в архіві немає.
Модель із попереднього великого архіву сюди не підходить.

CSV:
Підтримано 561 готову ознаку з твого Kaggle-датасету, назви колонок обов'язкові.
Activity та subject можна залишати або прибирати. Порядок ознак автоматично
відновлюється за model_info.json. Перетворення для моделі — те саме expand_dims,
що у твоєму ноутбуці. Інтерфейс показує перші 20 рядків і прогнозує всі рядки.

Сирий CSV з акселерометра/гіроскопа телефона — інший формат. Щоб залишити цю
модель і підтримати такі записи, треба окремо відтворити обчислення всіх 561
ознак і нормування UCI. Цього немає в цьому простому варіанті; програма явно
відхиляє несумісний CSV замість видавати неправильні результати.

Примітка для звіту: у твоєму початковому fit тестова частина використовується
також як validation_data. Тут це збережено заради повернення твого коду;
якщо за нею підбирати налаштування, результат не буде незалежною тестовою оцінкою.
